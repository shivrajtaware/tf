# उपसरपंच — Product-Grade HQ Operating Platform

## Current build
This repository is the local, product-grade frontend/workflow build for the उपसरपंच HQ operating platform.

### UX direction
- White foundation with a clearly visible cool-blue frosted glass layer.
- Large ambient blue/cyan/orange blurred surfaces behind the application shell.
- Translucent panels with strong backdrop blur, white highlight edges and restrained orange brand actions.
- Desktop-first HQ control tower; mobile-first franchise portal and driver workspace.
- Readable enterprise typography and generous spacing; no intentionally tiny admin-template typography.

### Usable local behaviors
- Local persistent transactional state in browser storage.
- HQ-assisted order creation with required assistance reason.
- Order status transitions, hold, selection, bulk approve/allocate and order detail workflow.
- Franchise self-service order/review/submit flow.
- Procurement PR/PO/GRN workspaces.
- Inventory adjustment/transfer/count/expiry/ledger workspaces.
- Production work order creation and operational status views.
- Dispatch trip creation and operational queue.
- Finance payment posting against an existing invoice balance.
- Quality/support ticket workflows.
- Notification acknowledge/resolve lifecycle.
- AI recommendation accept/edit/ignore/evidence interactions.
- Franchise portal: dashboard, material order, my orders, receiving, stock, invoices/payments, support and profile.
- Search, filters, selection, row detail drawers, column controls where provided, export controls, command palette, notifications and responsive navigation.
- Prisma relational schema included as the production data-model foundation.
